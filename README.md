# Synology Sync Manager (시놀로지 동기화 매니저)

Windows 데스크톱 환경에서 로컬 폴더를 시놀로지(Synology) NAS와 안전하게 백업 및 동기화하는 프로그램입니다.

## 주요 기능
- **📁 다중 동기화 폴더 지원:** 여러 개의 로컬 폴더와 NAS 원격 저장 경로 쌍을 자유롭게 추가 및 삭제 관리할 수 있습니다.
- **🗑️ 폴더별 삭제 동기화(미러링 삭제) 옵션:** 각 동기화 폴더마다 '로컬에서 삭제 시 NAS 백업 파일도 함께 삭제' 여부를 개별 설정할 수 있습니다. (기본값: 안전 보존)
- **⚡ 실시간 파일 변경 감지 동기화:** 등록된 모든 로컬 폴더의 변경 사항을 실시간 감시하며, 3초 디바운스 후 즉시 동기화합니다.
- **🔒 시놀로지 접속 비밀번호 암호화 저장:** Windows DPAPI 기반의 Electron `safeStorage`를 사용하여 `config.json`에 비밀번호가 안전하게 암호화되어 저장됩니다.
- **🖼️ 선명한 시스템 트레이 아이콘:** Windows 작업 표시줄 트레이에 전용 클라우드 동기화 아이콘이 상주하며 창 최소화 시에도 백그라운드 동기화를 유지합니다.
- **WebDAV 프로토콜:** HTTPS 기반으로 외부 인터넷(DDNS/공인IP) 및 자체 서명 SSL 환경을 완벽 지원합니다.
- **진행률 및 실시간 로그:** 파일별 전송 상태, 진행률(%), 오류 메시지를 실시간 모니터링할 수 있습니다.

## 실행 방법

### 1. 개발 모드 실행
```bash
npm start
```

### 2. 프로젝트 빌드
```bash
npm run build
```

### 3. 테스트 실행
```bash
npm test
```

## 시놀로지 NAS 사전 설정 안내
1. 시놀로지 DSM **패키지 센터**에서 **WebDAV Server**를 설치하고 실행합니다.
2. **HTTPS 활성화** (기본 포트: `5006`)를 체크합니다.
3. 공유기 사용 시 `5006` 포트포워딩 또는 QuickConnect/DDNS를 구성합니다.
4. 본 프로그램 UI에서 서버 주소(`https://[DDNS주소]:5006`), 아이디, 비밀번호를 입력하고 **[연결 테스트]**를 클릭하여 연결 여부를 확인합니다.
